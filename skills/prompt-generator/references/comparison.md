# Comparison and decision

Load when the delegated prompt compares sources, versions or alternatives.

Identify each object, baseline, decision audience and whether the output is reconciliation or a recommendation. Normalize version, scope, period, units, environment, workload and measurement method when applicable. Preserve original values and identify conversions. State hard constraints, criteria, priorities and tie-breakers. If priorities remain delegated, use explicit scenarios or sensitivity analysis. For each disagreement, cite evidence on both sides and distinguish measurement, definition, version, scope and factual conflict. Keep missing data explicit, with what would make a valid comparison possible.

Return a side-by-side matrix, evidence locations, differences and decision conditions. For a recommendation, state the conditions that would reverse it. When combined with implementation, specify the selected contract and acceptance checks carried into the next phase.

## Example

For a report with mean latency and another with p95, compare scope and test method and show both statistics with their original labels. Require a common statistic under equivalent load before producing a latency ranking.
