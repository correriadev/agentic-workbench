# Curated skills

Third-party source is fetched by immutable commit rather than vendored here.
`environment.lock.yaml` pins Caveman 4.0.1 and Ponytail 5.3.2. The personal profile
lists the selected Caveman skills; the adapter selects six Ponytail skills.

Built-in Codex skills and app/plugin runtime skills are documented in the
inventory and restored with the distributing product. They are not copied.
Unresolved local Jev snapshots are retained for review under `skills/authored`,
with their uncertain classification in `docs/research/local-assets.json`.
