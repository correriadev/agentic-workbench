# AGENTIC WORKBENCH

## STACK

Markdown skill contracts (`SKILL.md`); Python 3.12+ standard library (`project-memory` tools and tests); PowerShell and Bash utility scripts.

## ARCHITECTURE

Provider-neutral catalog of 13 self-contained engineering skills under `skills/<name>/SKILL.md` paired with lightweight architectural memory in `docs/`. Core pipeline enforces strict Maker-Checker separation across `scope-refinement` (tripartite spec: `SCOPE.md`, `tasks.json`, `qa.json`), `tdd-orchestrator` (Red-Green-Refactor construction), `adversarial-qa` (independent invariant/security verification), and `the-grumpy-tech-lead` (Socratic systemic review).
