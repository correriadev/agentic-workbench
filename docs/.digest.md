# Agentic Workbench Digest

## STACK & ARCHITECTURE
- **Pattern:** Modular Skill Catalog Architecture with decoupled, self-contained skills.
- **Languages:** Python (3.12+), PowerShell, Bash, Markdown.
- **Layers:** Core Engineering, Product & Discovery, Navigation & CLI Delegation, Operational Scripts.
- **DI & Coupling:** Zero runtime cross-skill imports; skills rely strictly on stdlib and self-contained assets.
- **Key Constraints:**
  - REQUIRED: Each skill must be self-contained in `skills/<name>/SKILL.md`.
  - REQUIRED: Maximum 10,000 characters per doc file (3,000 chars and < 60 lines for `.digest.md`).
  - PROHIBITED: Hardcoded runtime dependencies between sibling skills or external frameworks.

## TESTING & VERIFICATION
- **Frameworks:** Python `unittest`, PowerShell assertion suites.
- **Commands:**
  - Graph build: `python skills/project-memory/scripts/generate_docs_graph.py docs`
  - Ontology check: `python skills/project-memory/scripts/validate_ontology.py docs`
  - Skill sync dry-run: `python scripts/sync_skills.py --dry-run`
  - Offline CLI wrapper check: `powershell -File skills/ask-antigravity/scripts/Test-Invoke-Antigravity.ps1`
- **Gates:** 100% graph reference resolution, 100% ontology validation compliance, zero broken edges.

## DOCUMENTATION INDEX
- `docs/adr/ARCHITECTURE.md`: System architecture, skill modularity, layer boundaries, and code patterns.
- `docs/adr/TESTS.md`: Testing protocol, verification commands, mock matrix, and validation rules.

Required read `docs/.graph.json` for the complete document list, tags, and relations.

## ROUTING
- Use an exact supplied path directly when provided.
- Otherwise read `docs/.graph.json` to select target document and inspect 1-hop relations.
- Read `docs/adr/ARCHITECTURE.md` for architecture and layer boundary constraints.
- Read `docs/adr/TESTS.md` before executing or altering test suites.
