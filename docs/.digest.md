# AGENTIC WORKBENCH

## STACK

Markdown skill contracts (`SKILL.md`); Python 3.12+ standard library (`project-memory` tools and tests); PowerShell and Bash utility scripts.

## ARCHITECTURE

Provider-neutral skill catalog with lightweight architectural memory in `docs/`. `scope-refinement` emits `SCOPE.md`, `tasks.json`, and `qa.json`. The TDD triad separates `tdd-orchestrator` (DAG, batches, diff gates, task state, bounded RW-* rework), `tdd-maker` (strict RED-GREEN-REFACTOR within files_allowed, candidate commits, no qa.json access), and `adversarial-qa` (independent invariant/security verification). Two persistent detached worktrees, maker-slot and qa-slot, exchange pinned candidate OIDs; matching QA PASS gates fast-forward integration. Only QA authors findings/verdicts. `the-grumpy-tech-lead` provides systemic review. These are skill contracts; no standalone runner is required.
